# Changelog

## 1.2.0 — 2026-11-22

Безопасность и первый запуск:

- Пароли пользователей хранятся в виде хешей (Werkzeug pbkdf2/scrypt).
  Старые конфиги с открытыми паролями продолжают работать и постепенно
  заменяются при сохранении настроек.
- API безопасности больше не отдаёт пароли: только признак «пароль задан».
  Пустое поле в настройках означает «оставить прежний пароль».
- CSRF-защита для всех POST/PUT/DELETE: токен в сессии, скрытое поле в формах
  и заголовок `X-CSRF-Token` для fetch. Исключения — эндпоинты для ботов
  с отдельными секретами (`/api/relay/<id>/open`, `/api/bots/<id>/config`).
- Мастер первого запуска: пароль администратора — минимум 10 символов,
  обязательны буквы и цифры; пароль сохраняется только в виде хеша.
- Ключ сессий — `VIEWER_SECRET` или случайный файл `logs/.session_secret`.
- Ограничение попыток входа (10 за 10 минут), безопасный `next`-редирект,
  флаги cookie и защитные заголовки.
- `requirements.txt`: добавлен `python-dotenv`.
- CI: ruff, compileall, pytest (26 тестов).
