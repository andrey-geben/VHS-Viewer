Режим auto_tune

Когда включён — при старте viewer.py параметры objects_per_camera, analyze_every_n, object_imgsz, intra_op_num_threads автоматически подстраиваются под это железо. Per-camera настройки в YAML при этом не затрагиваются.

Как это работает

auto_tune анализирует количество физических ядер, объём RAM, текущую частоту CPU и предупреждает о троттлинге / работе от батареи.

На мощном сервере (8+ ядер, 16+ GB RAM) — включит полный режим: objects_per_camera: true, analyze_every_n: 1, object_imgsz: 640, intra_op_num_threads: 8.

На ноутбуке / слабом CPU (2–4 ядра) — консервативный режим: objects_per_camera: false, analyze_every_n: 2, object_imgsz: 416, intra_op_num_threads: 3.

Проверить рекомендации без запуска аналитики: python -m vhs_analytics.hardware. С бенчмарком: python -m vhs_analytics.hardware --benchmark.
