Назначение

Компактный веб-клиент для просмотра потоков VHS-Streamer. Показывает сетку WebRTC-потоков в браузере. Без авторизации, без записи — только трансляция.

Технологии

  • Python 3.12, Flask 3.0
  • WebRTC через MediaMTX
  • PyInstaller — сборка .exe
