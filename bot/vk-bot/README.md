# VK-бот

## Как получить токен

1. Откройте https://vk.com/groups и создайте сообщество (или возьмите существующее).
2. Управление → **Работа с API**.
3. **Создать ключ** → выберите права: `Управление сообществом`, `Сообщения сообщества`.
4. Скопируйте токен — он длинный, начинается с `vk1.a.`.
5. Там же: **Long Poll API** → включить → версия API 5.199+.

## Как узнать свой VK ID

- Запустите бота с пустым `VK_ALLOWED_IDS` и напишите ему `/id` — бот ответит вашим ID.
- Либо откройте свой профиль — в URL вида `vk.com/id123456789` число и есть ID.
